1 Functional Iteration and Fixed Points

[Textbook reference: §2.3]

Many of the methods we have seen (and ones we will see later in this course) generate sequences xn that converge to some limit r. The convergence of these methods can often be studied using a concept called functional iteration. Let I be some subset of ℝ, and let g:I→I. Starting from some initial x0, the functional iterates of g are given by

xn+1=g⁢(xn).
Example 1.

Let g⁢(x)=cos⁡(x). We consider the functional iteration starting from some different choices of x0. Note that for each of the starting values, the iteration appears to converge to the same value, r≈0.739085, which is a solution to g⁢(x)=x. ◆

The fact that the iteration in the example above converged to a solution to g⁢(x)=x is not a coincidence, as the following theorem tells us.

Theorem 1 (Limits of functional iteration; Textbook Theorem 2.19).

Suppose that x0 is given and that the sequence xn is generated by functional iteration using the function g, xn+1=g⁢(xn) for n≥0. If xn→r and g is continuous at r, then r is a fixed point of g, i.e. g⁢(r)=r.

Given this theorem, it is important to understand when a function g has a fixed point, and under what conditions will the functional iteration xn+1=g⁢(xn) converge to that fixed point. One useful result on the existence of a fixed point is the following.

Theorem 2 (A fixed point theorem; Textbook Theorem 2.3).

If g∈C⁢[a,b] and g⁢([a,b])⊆[a,b], then g has a fixed point r∈[a,b].

Proof.

Let f⁢(x)=g⁢(x)−x. Since g⁢(a),g⁢(b)∈[a,b], we have f⁢(a)≥0 and f⁢(b)≤0, so f⁢(a)⁢f⁢(b)≤0. By the convergence of the bisection method (Textbook Theorem 2.2), f has a root r∈[a,b], i.e. g⁢(r)=r. ∎

This theorem tells us that a fixed point exists, but not whether the functional iteration converges to it. The main tool that we will use to answer that question is the Contractive Mapping Theorem. First, we need some definitions.

Definition 1 (Contraction; Textbook Definition 2.20).

We say that g is a contraction (or contractive mapping) on I⊆ℝ if there is a constant 0≤γ<1 such that

|g⁢(x)−g⁢(y)|≤γ⁢|x−y|for all x,y∈I.
Lemma 1 (Textbook equation (2.12)).

Let I be an interval, and let g∈C1⁢(I). Then

|g⁢(x)−g⁢(y)|≤γ⁢|x−y|for all x,y∈Iif and only if|g′⁢(x)|≤γfor all x∈I.
Proof.

First, suppose that |g′⁢(x)|≤γ for all x∈I, and let x,y∈I. By the Mean Value Theorem,

|g⁢(x)−g⁢(y)|=|g′⁢(ξ)|⁢|x−y|≤γ⁢|x−y|

for some ξ between x and y, so |g′⁢(ξ)|≤γ.

Conversely, suppose that |g⁢(x)−g⁢(y)|≤γ⁢|x−y| for all x,y∈I, and let x∈I. For any y∈I with y≠x,

|g⁢(y)−g⁢(x)y−x|≤γ.

Taking the limit as y→x (with y∈I), we obtain |g′⁢(x)|≤γ. ∎

Definition 2 (Cauchy sequence; Textbook Definition 2.21).

A sequence {xn} in ℝ is a Cauchy sequence if, for each ε>0, there is a natural number N=N⁢(ε) such that |xm−xn|≤ε whenever m,n≥N.

Theorem 3 (Convergence of Cauchy sequences; Textbook Theorem 2.22).

Cauchy sequences in ℝ converge. In other words, if {xn} is a Cauchy sequence, then there is some r∈ℝ such that xn→r as n→∞.

Theorem 4 (Contractive mapping theorem; Textbook Theorem 2.23).

Let I⊆ℝ be a closed set. If g⁢(I)⊆I and g is a contraction on I with contraction constant 0≤γ<1, then the following hold:

  1. 1.

    g has a unique fixed point r∈I.

  2. 2.

    If x0∈I and xn+1=g⁢(xn), then xn→r.

  3. 3.

    The convergence is at least linear, with the error bounds

    |xn−r|≤γn⁢|x0−r|,|xn−r|≤γn1−γ⁢|x1−x0|.
Proof.

We first establish uniqueness: there is at most one fixed point in I. To do this, we suppose that r,s∈I are fixed points; we will show that r must equal s. Since they are fixed points,

|r−s|=|g⁢(r)−g⁢(s)|≤γ⁢|r−s|.

If |r−s|≠0, then, since γ<1, we would have |r−s|<|r−s|, a contradiction. Therefore, |r−s|=0, and r=s, establishing uniqueness. We now move on to proving existence.

Let xn+1=g⁢(xn). Since |xk+1−xk|=|g⁢(xk)−g⁢(xk−1)|≤γ⁢|xk−xk−1|, using induction we see that |xk+1−xk|≤γk⁢|x1−x0| for all k. Suppose that m>n, and consider |xm−xn|. We have

|xm−xn| =|∑k=nm−1(xk+1−xk)|≤∑k=nm−1|xk+1−xk|≤∑k=nm−1γk⁢|x1−x0|
=|x1−x0|⁢(∑k=0m−1γk−∑k=0n−1γk)=γn−γm1−γ⁢|x1−x0|≤γn1−γ⁢|x1−x0|.

Since the final term vanishes as n→∞, we see that {xn} is a Cauchy sequence, which therefore must converge to some number r∈ℝ. Since the terms of the sequence are all in I and I is closed, it holds that r∈I. Therefore, xn→r∈I. Since g is continuous at r, g⁢(xn)→g⁢(r). Therefore,

r=limn→∞xn+1=limn→∞g⁢(xn)=g⁢(r),

and so r is the unique fixed point of g in I.

We proved above that the inequality

|xm−xn|≤γn1−γ⁢|x1−x0|

holds for all m>n, so

limm→∞|xm−xn|=|r−xn|≤γn1−γ⁢|x1−x0|,

which establishes one of the error bounds. The other error bound follows readily by induction, using |xn+1−r|=|g⁢(xn)−g⁢(r)|≤γ⁢|xn−r|. ∎

Example 2.

We return to Example 1, and prove that for any x0∈ℝ, the functional iterates of g⁢(x)=cos⁡(x) converge to the same limit r, which must be a fixed point g⁢(r)=r. (Note that x=cos⁡(x) has only one solution, so the fixed point is unique).

Let I=[0,1]. Since cos is decreasing on [0,1], we have g⁢(I)=[cos⁡(1),cos⁡(0)]=[cos⁡(1),1]⊆I. For x,y∈I, the Mean Value Theorem gives

g⁢(x)−g⁢(y)x−y=cos′⁡(ξ)=−sin⁡(ξ)

for some ξ between x and y, and so

|g⁢(x)−g⁢(y)|=|sin⁡(ξ)|⁢|x−y|≤sin⁡(1)⁢|x−y|.

Therefore, g is a contraction on I with γ=sin⁡(1)≈0.8415. By the contractive mapping theorem (Theorem 4), g has a unique fixed point r∈[0,1], and the iteration converges to r whenever x0∈[0,1].

Now let x0∈ℝ be arbitrary. Then x1=cos⁡(x0)∈[−1,1], and since cos is even, x2=cos⁡(x1)=cos⁡(|x1|)∈[cos⁡(1),1]⊆I. Therefore, the iterates x2,x3,… are the functional iterates of g starting from x2∈I, and so xn→r. Furthermore,

|xn−r|≤γn−2⁢|x2−r|≤(sin⁡(1))n−2for n≥2.◆

The contractive mapping theorem guarantees convergence that is at least linear. The following theorem gives the precise order of convergence in terms of the derivatives of g at the fixed point.

Theorem 5 (Convergence rates; Textbook Theorem 2.26).

Let {xn} be a sequence generated by functional iteration with g, and let r be a fixed point of g, with xn≠r for all n.

  1. 1.

    If g∈C1 near r and 0<|g′⁢(r)|<1, then xn→r precisely linearly if x0 is sufficiently close to r.

  2. 2.

    Let m≥2. If g∈Cm near r and g(j)⁢(r)=0 for 1≤j≤m−1, but g(m)⁢(r)≠0, then xn→r with precisely order m if x0 is sufficiently close to r.

Proof.

In either case, there is a constant γ∈[0,1) and an interval [r−δ,r+δ] with δ>0 on which |g′⁢(x)|≤γ. By Lemma 1, g is a contraction on [r−δ,r+δ]. Furthermore, for x∈[r−δ,r+δ], taking y=r and using g⁢(r)=r, we have |g⁢(x)−r|≤γ⁢|x−r|≤δ, so g⁢(x)∈[r−δ,r+δ]. By the contractive mapping theorem (Theorem 4), convergence is guaranteed if x0∈[r−δ,r+δ].

In the first case,

|xn+1−r||xn−r|=|g⁢(xn)−g⁢(r)||xn−r|=|g′⁢(ξn)|

for some ξn between xn and r. Therefore, |xn+1−r|/|xn−r|→|g′⁢(r)|∈(0,1), and we see that the rate of convergence is precisely linear. In the second case, repeated applications of l’Hôpital’s rule reveal that

limx→rg⁢(x)−r(x−r)m=limx→rg′⁢(x)m⁢(x−r)m−1=⋯=limx→rg(m)⁢(x)m!=g(m)⁢(r)m!,

so |xn+1−r|/|xn−r|m→|g(m)⁢(r)|/m!≠0, and the rate of convergence is precisely order m. ∎

Example 3.

We return again to Example 1, and show that the convergence is precisely linear. We have g′⁢(r)=−sin⁡(r). Since r∈(0,1), we have 0<sin⁡(r)<sin⁡(1)<1, so 0<|g′⁢(r)|<1 (numerically, |g′⁢(r)|=sin⁡(r)=1−r2≈0.6736). By Theorem 5, the convergence is precisely linear if x0 is sufficiently close to r.

Since we showed above that xn→r for any x0, the iterates eventually come arbitrarily close to r, and so the convergence is precisely linear for any x0 (provided xn≠r for all n). To see this directly, by the Mean Value Theorem,

|xn+1−r||xn−r|=|g⁢(xn)−g⁢(r)||xn−r|=|sin⁡(ξn)|

for some ξn between xn and r. Since xn→r, also ξn→r, and so

|xn+1−r||xn−r|→sin⁡(r)≈0.6736.◆
