1 Orders of Convergence

[Textbook reference: §1.2]

In the previous lecture, we saw two types of numerical methods. We saw the midpoint method, a type of quadrature that approximates integrals using a function evaluation at the midpoint of the interval, and finite difference quotients, which approximate derivatives at a point using multiple function evaluations. In both of these examples, we were able to compute the error of the approximation. Recall that the (signed) errors of these approximations are

(Midpoint Rule) ∫abf⁢(x)⁢𝑑x−f⁢(c)⁢(b−a) =f′′⁢(z)24⁢h3,
(Forward Difference) f′⁢(c)−f⁢(c+h)−f⁢(c)h =−f′′⁢(y+)2⁢h,
(Backward Difference) f′⁢(c)−f⁢(c)−f⁢(c−h)h =f′′⁢(y−)2⁢h,
(Centered Difference) f′⁢(c)−f⁢(c+h)−f⁢(c−h)2⁢h =−h26⋅f′′′⁢(z+)+f′′′⁢(z−)2,

where c=(a+b)/2, z∈(a,b), and h=b−a for the midpoint rule, and y+,z+∈(c,c+h) and y−,z−∈(c−h,c) for the difference quotients.

In each of these four cases, the error scales in terms of h, which we can think of as a parameter. As h→0, then the errors also go to zero, meaning that the approximations become more and more accurate. We mentioned before that the centered difference approximation is more accurate (at least for small h) than either the forward or backward difference approximations. This is because if we halve h, then the centered error is (roughly) divided by four, but the forward and backward errors are divided by two. So the centered error shrinks much faster.

We want to study this type of convergence behavior. Consider some quantity L that we wish to approximate (for example, the integral or derivative of f⁢(x)), and, for given h>0, an approximation Lh. If the approximation converges, then Lh→L as h→0. Sometimes we may have approximations Ln such that Ln→L as n→∞, where n is usually an integer parameter; we will see examples later (e.g. Gaussian quadrature). We want to quantify and classify how fast Lh converges to L as h→0.

Definition 1 (Order of convergence).

Let {Lh} be a family of approximations of L, with Lh→L as h→0. Given p>0, not necessarily an integer, we say that the convergence is of order p when there are constants C,h0>0 such that

|L−Lh|≤C⁢hpwhenever 0<h≤h0. (1)

If {Ln} is a sequence of approximations to L, with Ln→L as n→∞, then we say that the convergence is of order p if there exist constants C,N>0 such that

|L−Lh|≤C⁢n−pwhenever n>N. (2)

It will be very useful when discussing orders of convergence to use big-𝒪 notation. This notation is encountered frequently in computer science, when discussing the concept of computational complexity. In our context, the idea is the same, but the setting is slightly different. We write ah=𝒪⁢(g⁢(h)) as h→0 to express that there exist constants C,h0>0 such that |ah|≤C⁢g⁢(h) for all 0<h≤h0. When it is clear from context, we will omit the phrase “as h→0”. So,

|L−Lh|=𝒪⁢(hp)means the same thing asLh converges to L with order p.

Note that if ah=𝒪⁢(hp) then ah=𝒪⁢(hq) for all 0<q≤p. We prefer to write 𝒪⁢(hp) for the largest p for which it holds.

For a sequence an, we write an=𝒪⁢(g⁢(n)) as n→∞ to mean that there exist constants C,N>0 such that |an|≤C⁢g⁢(n) for all n≥N. So, in the case of Ln→L as n→∞ at order p, we write |L−Ln|=𝒪⁢(n−p).

Note that functions g⁢(h) or g⁢(n) other than hp or n−p are commonly encountered. For example, we might see an=𝒪⁢(n⁢log⁡n) or an=𝒪⁢(e−n).

1.1 Estimating Orders of Convergence

As an example, let f⁢(x)=arctan⁡(x), and let c=3. We can compute that f′⁢(c)=1/4. How well do the forward, backward, and centered difference quotients approximate f′⁢(c)? Let F⁢(h)=(f⁢(c+h)−f⁢(c))/h, B⁢(h)=(f⁢(c)−f⁢(c−h))/h, and C⁢(h)=(f⁢(c+h)−f⁢(c−h))/(2⁢h). We know from the expressions for the errors that

|f′⁢(c)−F⁢(h)| =𝒪⁢(h),
|f′⁢(c)−B⁢(h)| =𝒪⁢(h),
|f′⁢(c)−C⁢(h)| =𝒪⁢(h2).

Can we verify these results numerically? We compute the difference quotients for h=2−n, n=0,1,2,… (i.e. successive halvings of h). Let E⁢(h) denote the error associated with one of the approximations. Then, E⁢(h)=𝒪⁢(hp) for p=1 (forward, backward) or p=2 (centered). If we assume that E⁢(h)=C⁢hp for some constant C>0, then

E⁢(h)E⁢(h/2)=C⁢hpC⁢(h/2)p=hphp/2p=2p.

So, for the forward and backward difference quotients, we would expect E⁢(h)/E⁢(h/2)≈2, and for the centered difference, we would expect E⁢(h)/E⁢(h/2)≈4.

Slightly more generally, again under the assumption that E⁢(h)=C⁢hp, if we have two values h1 and h2, then

E⁢(h1)E⁢(h2)=C⁢h1pC⁢h2p=(h1h2)p.

If we just have the value of the right-hand side of the above expression, we can recover the value of p by computing

p=logh1/h2⁡((h1h2)p)=log⁡(E⁢(h1)/E⁢(h2))log⁡(h1/h2).

We usually use log interchangeably with ln (natural logarithm, base e), but the above expression is independent of the base of logarithm chosen. In the case described earlier, since we considered successive halvings of h, we could estimate the order of convergence by computing log2⁡(E⁢(h)/E⁢(h/2)). This means that if we plot the error as a function of h on a log-log plot, then we expect to observe straight lines with slopes of 1 (forward and backward difference) and 2 (centered difference). 1.2 Richardson Extrapolation

Richardson extrapolation is a common approach for accelerating convergence when some theoretical knowledge of the structure of the error L−Lh is known. For example, L−Lh might be expressed in terms of an expansion in powers of h. We motivate the discussion of Richardson extrapolation by revisiting the centered difference approximation Lh=ϕ⁢(h)=f⁢(c+h)−f⁢(c−h)2⁢h of L=f′⁢(c). For simplicity, we assume that f is analytic near c and that h>0 is sufficiently small, so we have

f′⁢(c)=ϕ⁢(h)−f(3)⁢(c)3!⁢h2−f(5)⁢(c)5!⁢h4−f(7)⁢(c)7!⁢h6−⋯. (3)

Replacing h by h/2 in this formula, we obtain

f′⁢(c)=ϕ⁢(h/2)−f(3)⁢(c)3!⁢122⁢h2−f(5)⁢(c)5!⁢124⁢h4−f(7)⁢(c)7!⁢126⁢h6−⋯. (4)

Both ϕ⁢(h) and ϕ⁢(h/2) are 𝒪⁢(h2) approximations of f′⁢(c), but a simple combination of the two eliminates the h2 term in the error expansions, yielding an 𝒪⁢(h4) approximation. Subtracting 22⁢ϕ⁢(h/2) from ϕ⁢(h) (i.e. subtracting 22 times (4) from (3)) cancels the h2 term, and we obtain

ϕ⁢(h)−22⁢ϕ⁢(h/2)=−(22−1)⁢f′⁢(c)+34⁢f(5)⁢(c)5!⁢h4+1516⁢f(7)⁢(c)7!⁢h6+⋯,

and so

f′⁢(c)=22⁢ϕ⁢(h/2)−ϕ⁢(h)22−1+14⁢f(5)⁢(c)5!⁢h4+516⁢f(7)⁢(c)7!⁢h6+⋯.

We have taken a linear combination of two instances of the same approximation method for f′⁢(c) to obtain a new approximation of higher order. This process is called Richardson extrapolation.

Now we will do the same process, but with slightly different notation in order to illustrate the general principle. Write ϕ0⁢(h)=ϕ⁢(h), so

L =ϕ0⁢(h)+∑k=1∞ak,0⁢h2⁢k
=ϕ0⁢(h/2)+∑k=1∞ak,0⁢(h/2)2⁢k,

where ak,0=−f(2⁢k+1)⁢(c)(2⁢k+1)!. We want to cancel the k=1 term in the error, which for ϕ0⁢(h) is a1,0⁢h2 and for ϕ0⁢(h/2) is a1,0⁢(12)2⁢h2, and so we take 22 times ϕ0⁢(h/2) minus ϕ0⁢(h), and then normalize, giving

L=22⁢ϕ0⁢(h/2)−ϕ0⁢(h)22−1+∑k=2∞22−2⁢k−122−1⁢ak,0⁢h2⁢k=ϕ1⁢(h)+∑k=2∞ak,1⁢h2⁢k,

where ϕ1⁢(h)=(22⁢ϕ0⁢(h/2)−ϕ0⁢(h))/(22−1) and ak,1=22−2⁢k−122−1⁢ak,0. Note that the ϕ1⁢(h) approximation has higher order of convergence, since the error term starts at k=2. The error scales as h4, so the convergence is fourth order. The important thing to notice here is that this process can now be repeated to cancel the leading order term in the error for ϕ1⁢(h). Richardson extrapolation can be applied to L=ϕ1⁢(h)+∑k=2∞ak,1⁢h2⁢k where now we need to cancel the k=2 term in the remainder. By the same procedure, we need to take 24⁢ϕ1⁢(h/2)−ϕ1⁢(h) and normalize by 24−1 in the denominator, giving

L=24⁢ϕ1⁢(h/2)−ϕ1⁢(h)24−1+∑k=3∞24−2⁢k−124−1⁢ak,1⁢h2⁢k=ϕ2⁢(h)+∑k=3∞ak,2⁢h2⁢k,

where ϕ2⁢(h)=(24⁢ϕ1⁢(h/2)−ϕ1⁢(h))/(24−1) and ak,2=24−2⁢k−124−1⁢ak,1. Now, the error term starts at k=3, so the error for ϕ2⁢(h) scales as h6 and the convergence is sixth order. This process could be repeated again, canceling the k=3 term in the error associated with ϕ2, and so on. Notice that we did not need to know the coefficients ak,n of the error term. We just needed to know the general form of the error. This procedure is formalized in the following theorem.

Theorem 1 (Richardson extrapolation, even powers).

Suppose that, for all h>0 sufficiently small, the function ϕ⁢(h) approximates the number L with error expansion

L=ϕ⁢(h)+∑k=1∞ak⁢h2⁢k (5)

for some coefficients ak. Taking ϕ0=ϕ, we define the nth Richardson extrapolation, ϕn, recursively:

ϕn⁢(h)=22⁢n⁢ϕn−1⁢(h/2)−ϕn−1⁢(h)22⁢n−1=ϕn−1⁢(h/2)+ϕn−1⁢(h/2)−ϕn−1⁢(h)22⁢n−1for ⁢n≥1. (6)

If we set ak,0=ak for k≥1, then

L=ϕn⁢(h)+∑k=n+1∞ak,n⁢h2⁢kfor ⁢n≥0, (7)

where ak,n=22⁢n−2⁢k−122⁢n−1⁢ak,n−1 for k≥n+1.

Proof.

We prove this by induction on n. The base case n=0 is just the statement (5), so it holds by assumption. Fix n≥1 and assume that

L=ϕn−1⁢(h)+∑k=n∞ak,n−1⁢h2⁢k.

We have

22⁢n⁢L =22⁢n⁢ϕn−1⁢(h/2)+an,n−1⁢h2⁢n+∑k=n+1∞22⁢n−2⁢k⁢ak,n−1⁢h2⁢k,
L =ϕn−1⁢(h)+an,n−1⁢h2⁢n+∑k=n+1∞ak,n−1⁢h2⁢k.

Subtracting the second from the first, and then dividing by 22⁢n−1, we obtain

L=22⁢n⁢ϕn−1⁢(h/2)−ϕn−1⁢(h)22⁢n−1+∑k=n+1∞22⁢n−2⁢k−122⁢n−1⁢ak,n−1⁢h2⁢k.

But this is precisely (7) because of how we recursively defined ϕn and ak,n. ∎

Example 1 (Richardson extrapolation table).

In the context of Theorem 1, we fix (sufficiently small) h>0 and define the numbers R⁢(m,n)=ϕn⁢(2n−m⁢h) for 0≤n≤m. Fixing N>1, we may fill out a Richardson extrapolation table,

R⁢(0,0)R⁢(1,0)R⁢(1,1)R⁢(2,0)R⁢(2,1)R⁢(2,2)⋮⋮⋮⋱R⁢(N,0)R⁢(N,1)R⁢(N,2)⋯R⁢(N,N)

It holds that

R⁢(m,n)=22⁢n⁢R⁢(m,n−1)−R⁢(m−1,n−1)22⁢n−1, (8)

so only the initial column R⁢(m,0)=ϕ0⁢(2−m⁢h)=ϕ⁢(2−m⁢h) needs to be computed using ϕ; all other columns may be computed by the given recursion. For each fixed n, the entries R⁢(m,n) are all 𝒪⁢(h2⁢n+2) approximations of L.

Let L=1/3=f′⁢(c), where f⁢(x)=arctan⁡x, c=2, and ϕ⁢(h)=(f⁢(c+h)−f⁢(c−h))/(2⁢h). We fill out the first column of the table with ϕ⁢(1),ϕ⁢(1/2),…,ϕ⁢(1/32) and use the recursion (8) to complete the Richardson table. The absolute errors E⁢(m,n)=|L−R⁢(m,n)|, 0≤n≤m≤5, are given below.

m=0 5.937×10−2
m=1 1.544×10−2 7.950×10−4
m=2 3.861×10−3 1.504×10−6 5.139×10−5
m=3 9.647×10−4 5.868×10−7 7.262×10−7 7.802×10−8

m=5 6.028×10−5 3.087×10−9 1.681×10−10 1.965×10−12 1.130×10−13 5.322×10−14

The ratios of successive errors in the initial (zeroth) column quickly approach 22=4, as expected, which corresponds to quadratic convergence, 𝒪⁢(h2). In the next column, the ratios of successive errors are getting closer to the expected value of 24=16 that corresponds to quartic convergence, 𝒪⁢(h4). More generally, we have E⁢(m,n)=𝒪⁢(h2⁢(n+1)), so we expect E⁢(m−1,n)/E⁢(m,n)→22⁢(n+1) as m→∞ for each fixed n. ◆
