1 Building Polynomials

[Textbook reference: §3.1]

Many of the methods we have seen so far have been based on the idea of approximating a function by a polynomial. For example, the midpoint rule, and forward, backward, and centered difference can all be seen as approximating f by its secant. Similarly, regula falsi, Newton’s method, and secant method all use linear (tangent or secant) approximations to f. These are just a few of the many important examples of applications of polynomial approximation. Given these, it is important to understand how we can build polynomial approximants to given functions with certain properties.

Let n≥0. Let ℙn denote the space of polynomials of degree at most n. Note, this is the space of polynomials because this forms a vector space under the usual addition and scalar multiplication operations. The dimension of this space is n+1. The monomial basis (or standard basis) for ℙn is {1,x,x2,⋯,xn}. The standard form of a polynomial is expressed in terms of this basis,

p⁢(x)=∑k=0nak⁢xk=a0+a1⁢x+⋯+an⁢xn.

The largest k such that ak≠0 is called the leading coefficient of p, and we write deg⁡(p)=k.

Definition 1 (Root multiplicity; Textbook Definition 3.1).

If p⁢(x)=(x−r)k⁢q⁢(x) for k∈ℕ and some polynomial q satisfying q⁢(r)≠0, we say that r is a root of multiplicity k of p. When r is a root of multiplicity 1, it is called a simple root.

It can be shown that r is a root of multiplicity k of a polynomial p if and only if p(j)⁢(r)=0 for 0≤j≤k−1, but p(k)⁢(r)≠0.

Theorem 1 (Fundamental theorem of algebra and consequences; Textbook Theorem 3.2).

Let p∈ℙn for some n≥1. The following hold:

  1. 1.

    If deg⁡(p)=n (so an≠0), then p has precisely n roots in ℂ, r1,…,rn, counting multiplicities. Furthermore,

    p⁢(x)=an⁢∏k=1n(x−rk)=an⁢(x−r1)⁢⋯⁢(x−rn).
  2. 2.

    If p has more than n roots, counting multiplicities, then p=0.

Although the monomial basis is the one we are most familiar with, there are other bases that may be (much) more useful in actual computations. To give one motivating example, we discuss interpolating polynomials. A function f interpolates points (xi,yi) if it satisfies f⁢(xi)=yi. For a collection of distinct points xi and values yi, for i=0,1,…,n, we can construct an interpolating polynomial,

p⁢(x)=∑j=0n(yj⁢∏k=0k≠jnx−xkxj−xk).

The interpolation property can be verified by plugging in xj, and noticing that all but one term in the sum vanish. In this representation, yj are the coefficients of the so-called Lagrange basis functions.

  • •

    Shifted monomial basis. Given a number c, the shifted monomial basis is {1,x−c,(x−c)2,…,(x−c)n}. This is the basis used for Taylor polynomials.

  • •

    Lagrange basis. Given distinct numbers {x0,…,xn}, the Lagrange polynomials are

    ℓj⁢(x)=∏k=0k≠jnx−xkxj−xk.

    Each of these polynomials is of degree n, and they satisfy the Kronecker delta property,

    ℓj⁢(xi)=δi⁢j:={1,i=j,0,i≠j.

    Note that ∑j=0nℓj⁢(x)=1.

  • •

    Newton basis. Similar to the Lagrange basis, the Newton polynomials are given by

    wj⁢(x)=∏k=0j−1(x−xk).

    Note that deg⁡(wj)=j and wj⁢(xi)=0 when j>i.

1.1 Constraints and Functionals

Since ℙn is an (n+1)-dimensional vector space, we expect that an element of ℙn+1 can be determined by n+1 constraints. We will soon given conditions on a set of n+1 constraints that will guarantee that they will determine a unique polynomial. This will rely on the concept of a linear functional.

Definition 2.

A linear functional on a vector space V is a function ϕ:V→ℝ satisfying

ϕ⁢(u+v)=ϕ⁢(u)+ϕ⁢(v),andϕ⁢(c⁢u)=c⁢ϕ⁢(u),

for all u,v∈V and c∈ℝ.

In other words, a functional is a linear operator from V to ℝ. As two examples of linear functionals on ℙn:

  • •

    Evaluation at a point. For c∈ℝ and integer j≥0, ϕ⁢(p)=p(j)⁢(c).

  • •

    Integration on an interval. For a<b and an integer j≥0, ϕ⁢(p)=∫abp⁢(x)⁢xj⁢𝑑x.

We can verify that these are linear functionals by directly checking the definition and using linearity of the derivative and integral.

Lemma 1 (Unique determination of p∈ℙn; Textbook Lemma 3.4).

Suppose that ϕj:ℙn→ℝ, 0≤j≤n, are functionals. The following are equivalent:

  1. 1.

    The only p∈ℙn for which ϕ0⁢(p)=ϕ1⁢(p)=⋯=ϕn⁢(p)=0 is p=0.

  2. 2.

    For each set of numbers {y0,…,yn}, there is a unique polynomial p∈ℙn satisfying ϕj⁢(p)=yj for each 0≤j≤n.

Proof.

Let Φ:ℙn→ℝn+1 be the linear transformation given by Φ⁢(p)=(ϕ0⁢(p),…,ϕn⁢(p)). The range and nullspace of Φ are, respectively, ℛ⁢(Φ)={Φ⁢(p):p∈ℙn}⊂ℝn+1 and 𝒩⁢(Φ)={p∈ℙn:Φ⁢(p)=0}⊂ℙn. By the Rank-Nullity Theorem, dimℛ⁢(Φ)+dim𝒩⁢(Φ)=dimℙn=n+1. The first condition is the same as saying that 𝒩⁢(Φ)={0}, from which we determine that dimℛ⁢(Φ)=n+1. Since dim(ℝn+1)=n+1, this implies that ℛ⁢(Φ)=ℝn+1, which is equivalent to the second condition. Conversely, the second condition is the same as saying that Range⁡(Φ)=ℝn+1, from which we determine that dim(Nullspace⁡(Φ))=0, i.e. Nullspace⁡(Φ)={0}, which is equivalent to the first condition. ∎

We give a second proof, which also provides a means of constructing the desired polynomial. If we take (b0,b1,…,bn) to be a basis for ℙn, we can recast both conditions above in terms of matrix algebra. Any p∈ℙn is uniquely identified with a coefficient vector c=(c0,…,cn)∈ℝn+1 by its unique representation with respect to the basis, p⁢(x)=c0⁢b0⁢(x)+⋯+cn⁢bn⁢(x). Letting A∈ℝ(n+1)×(n+1) be defined by ai⁢j=ϕi⁢(bj) for 0≤i,j≤n, the two conditions can be rephrased as follows:

  1. 1.

    The only c∈ℝn+1 for which A⁢c=0 is c=0.

  2. 2.

    For each y∈ℝn+1, there is a unique c∈ℝn+1 such that A⁢c=y.

Either of these two statements (conditions) imply the other, and both imply that A is invertible. Using c=A−1⁢y, we can construct p in terms of the basis.

The Fundamental Theorem of Algebra provides the standard tool for checking Condition 1 of Lemma 1 for a set of functionals that employ evaluation at a point.

Theorem 2 (Interpolating polynomial; Textbook Theorem 3.5).

Suppose that {x0,…,xn} are distinct. For each set of numbers {y0,…,yn}, there is a unique polynomial p∈ℙn satisfying p⁢(xj)=yj for each j.

Proof.

We define the functionals ϕj by ϕj⁢(p)=p⁢(xj) for p∈ℙn. Suppose that p∈ℙn, and ϕj⁢(p)=0 for each j. This means that p has at least n+1 distinct roots, one at each xj. But the degree of p is at most n, so the only way that it can have more than n distinct roots is if it is the constant polynomial p=0 (by Theorem 1). Now we apply Lemma 1 to complete the proof. ∎

Example 1 (Vandermonde matrix; Textbook Example 3.6).

If we were to give an interpolating polynomial in terms of the monomial basis, p⁢(x)=∑j=0naj⁢xj, the interpolation conditions, p⁢(xi)=yi for 0≤i≤n, would naturally lead to an (n+1)×(n+1) linear system involving a Vandermonde matrix

(1x0⋯x0n1x1⋯x1n⋮⋮⋮1xn⋯xnn)⁢(a0a1⋮an)=(y0y1⋮yn).

Similarly, using the shifted monomial basis, p⁢(x)=∑j=0naj⁢(x−c)j, we obtain the linear system

(1x0−c⋯(x0−c)n1x1−c⋯(x1−c)n⋮⋮⋮1xn−c⋯(xn−c)n)⁢(a0a1⋮an)=(y0y1⋮yn).

This approach is rarely used for practical numerical computations where interpolation is the focus, but it can be helpful in deriving finite difference approximations of derivatives of a function. Theorem 2 implies that the Vandermonde matrix is invertible. It is an exercise to show that, for any numbers {z0,z1,…,zn}, the corresponding Vandermonde determinant is given by

|1z0⋯z0n1z1⋯z1n⋮⋮⋮1zn⋯znn|=∏i<j(zj−zi)=∏i=0n−1∏j=i+1n(zj−zi).

If the numbers are distinct, this determinant is clearly non-zero. ◆

Example 2 (Newton basis; Textbook Example 3.6).

If the interpolating polynomial is given in the Newton basis, p⁢(x)=∑j=0ncj⁢wj⁢(x), the associated linear system is

(w0⁢(x0)w0⁢(x1)w1⁢(x1)⋮⋮⋱w0⁢(xn)w1⁢(xn)⋯wn⁢(xn))⁢(c0c1⋮cn)=(y0y1⋮yn).

We note that the first column of this matrix consists only of ones, since w0⁢(x)=1. The empty space above the diagonal entries indicates that these entries are zero. This is because, for j>i, the product

wj⁢(xi)=∏k=0j−1(xi−xk)

contains the factor (xi−xi)=0 (since 0≤i≤j−1), so wj⁢(xi)=0 whenever j>i. Since the matrix is lower-triangular, it is straightforward to solve the system by substitution, but we will later see that the notion of divided differences provides a more efficient way of computing the coefficients. ◆

Theorem 3 (Taylor polynomial; Textbook Theorem 3.7).

Let c∈ℝ. For each set of numbers {y0,…,yn}, there is a unique polynomial p∈ℙn satisfying p(j)⁢(c)=yj for each j.

Proof.

We define the functionals ϕj by ϕj⁢(p)=p(j)⁢(c) for p∈ℙn. Suppose that p∈ℙn, and ϕj⁢(p)=0 for each j. This means that p has a root of multiplicity at least n+1 at c. But the degree of p is at most n, so it must be the constant polynomial p=0 (by Theorem 1). Now we apply Lemma 1 to complete the proof. In this case, we can verify directly that

p⁢(x)=∑j=0nyjj!⁢(x−c)j

is this unique polynomial. ∎

In particular, if yj=f(j)⁢(c) for some function f, then this unique polynomial is exactly the degree-n Taylor polynomial of f centered at c.

Example 3 (Vandermonde inverse; Textbook Example 3.8).

Let {x0,…,xn} be distinct numbers, and let ℓj∈ℙn, 0≤j≤n, be the associated Lagrange polynomials. Let c be another number, which may or may not be one of the xj. According to Theorem 3, we can re-express each Lagrange polynomial in the shifted monomial basis as

ℓj⁢(x)=∑k=0nℓj(k)⁢(c)k!⁢(x−c)k.

This simple change of basis tells us something useful about the inverse of the Vandermonde matrix,

V=(1x0−c⋯(x0−c)n1x1−c⋯(x1−c)n⋮⋮⋮1xn−c⋯(xn−c)n).

Specifically, if we define the matrix U by ui⁢j=ℓj(i)⁢(c)/i! for 0≤i,j≤n, then the (i,j) entry of V⁢U is

[V⁢U]i⁢j=∑k=0n(xi−c)k⁢ℓj(k)⁢(c)k!=ℓj⁢(xi)=δi⁢j.

This tells us that V⁢U=I, so U=V−1, i.e.

V−1=(ℓ0⁢(c)ℓ1⁢(c)⋯ℓn⁢(c)ℓ0′⁢(c)ℓ1′⁢(c)⋯ℓn′⁢(c)ℓ0′′⁢(c)/2ℓ1′′⁢(c)/2⋯ℓn′′⁢(c)/2⋮⋮⋮ℓ0(n)⁢(c)/n!ℓ1(n)⁢(c)/n!⋯ℓn(n)⁢(c)/n!).

This relationship will be of use later for deriving some schemes for approximating derivatives. ◆

Although most of this chapter concerns polynomial approximations for which values of the polynomial, and possibly some derivatives, are specified at given points, we will also consider polynomials that are defined in terms of integral moments, as in the following theorem.

Theorem 4 (Least-squares approximation; Textbook Theorem 3.9).

Let a,b∈ℝ with a<b. For each set of numbers {y0,…,yn}, there is a unique polynomial p∈ℙn satisfying ∫abp⁢(x)⁢(x−a)j⁢𝑑x=yj for each j.

Proof.

In this case, we take ϕj to be ϕj⁢(p)=∫abp⁢(x)⁢(x−a)j⁢𝑑x. Now suppose that p∈ℙn, and ϕj⁢(p)=0 for 0≤j≤n. Well, p⁢(x)=∑j=0ncj⁢(x−a)j for some coefficients cj, so we see that

0=∑j=0ncj⁢ϕj⁢(p)=∑j=0ncj⁢∫abp⁢(x)⁢(x−a)j⁢𝑑x=∫abp⁢(x)⁢∑j=0ncj⁢(x−a)j⁢d⁢x=∫ab[p⁢(x)]2⁢𝑑x.

Since p2 is non-negative and continuous on [a,b], the only way it can integrate to zero is if p2=0 on [a,b], which implies that p=0 (everywhere). This completes the proof. ∎
