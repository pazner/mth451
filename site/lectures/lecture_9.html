1 Lagrange Interpolation: Error Estimates

[Textbook reference: §3.4]

We previously saw interpolation of data points (xi,yi). We mentioned that a common case we encounter is when yi=f⁢(xi) for some function f that we wish to approximate.

Our question is: can we quantify how well the polynomial interpolant p approximates the given function f?

The following theorem summarizes the main error estimate.

Theorem 1 (Lagrange Interpolation Error Theorem).

Suppose that f∈Cn+1⁢[a,b], and p∈ℙn interpolates f at the distinct nodes {x0,x1,…,xn}⊂[a,b]. For each x∈[a,b] there is a ξ⁢(x)∈[a,b] for which

f⁢(x)−p⁢(x)=f(n+1)⁢(ξ⁢(x))(n+1)!⁢∏j=0n(x−xj)=f(n+1)⁢(ξ⁢(x))(n+1)!⁢ℓ⁢(x), (1)

where ℓ⁢(x) is defined by

ℓ⁢(x)=∏j=0n(x−xj)=(x−x0)⁢(x−x1)⁢⋯⁢(x−xn).

Furthermore, ξ⁢(x) may be chosen (for each x) in such a way that f(n+1)⁢(ξ⁢(x)) is continuous on [a,b].

Now fix 1≤k≤n. There are distinct points {ξk,0,…,ξk,n−k}⊂(a,b) such that, for each x∈[a,b], there is a ξk⁢(x)∈(a,b) for which

f(k)⁢(x)−p(k)⁢(x)=f(n+1)⁢(ξk⁢(x))(n−k+1)!⁢∏j=0n−k(x−ξk,j). (2)

Furthermore, ξk⁢(x) may be chosen (for each x) in such a way that f(n+1)⁢(ξk⁢(x)) is continuous on [a,b].

We will prove this theorem later in this lecture.

In the special case that k=1 and x=xj is one of the interpolation nodes, we can improve upon (2) as follows:

f′⁢(xj)−p′⁢(xj)=f(n+1)⁢(ξ⁢(xj))(n+1)!⁢∏k=0k≠jn(xj−xk)=f(n+1)⁢(ξ⁢(xj))λj⁢(n+1)!,

where λj are the barycentric weights.

The above results measure the error between f and the interpolating polynomial p at one specific point. In order to give some notion of how close one function is to another, it will be useful for us to consider measures of error that consider more than just a single point. The tools that we use to do this are called norms, which assign a “size” to functions. As one particularly useful example, we consider the maximum norm.

Definition 1 (Max Norm).

For f∈C⁢[a,b], we define

‖f‖C⁢[a,b]=maxx∈[a,b]⁡|f⁢(x)|.

This defines a norm on C⁢[a,b], and can be thought of as measuring the “size” or “length” of f on the closed interval [a,b]. For two functions f,g∈C⁢[a,b], ‖f−g‖C⁢[a,b] is a natural measure of the “distance” between them.

Example 1.

Suppose that p∈ℙ2 interpolates a function f∈C3⁢[−2,1] at the nodes {−1,0,1}, and let ℓ⁢(x)=(x+1)⁢x⁢(x−1) denote the associated node polynomial. For x∈[−2,1], the error formulas from Theorem 1 are the following:

  1. 1.

    f⁢(x)−p⁢(x)=f′′′⁢(ξ⁢(x))6⁢ℓ⁢(x) for some ξ⁢(x) between min⁡{x,−1} and max⁡{x,1};

  2. 2.

    f′⁢(x)−p′⁢(x)=f′′′⁢(ξ1⁢(x))2⁢(x−ξ1,0)⁢(x−ξ1,1), where ξ1,0∈(−1,0), ξ1,1∈(0,1), and ξ1⁢(x) is (strictly) between min⁡{x,ξ1,0} and max⁡{x,ξ1,1};

  3. 3.

    f′′⁢(x)−p′′⁢(x)=f′′′⁢(ξ2⁢(x))⁢(x−ξ2,0), where ξ2,0∈(−1,1), and ξ2⁢(x) is (strictly) between x and ξ2,0.

We use the first of these formulas to bound the error f−p in the max norm. If x∈[−1,1], then ξ⁢(x)∈[−1,1] as well, and so |f′′′⁢(ξ⁢(x))|≤‖f′′′‖C⁢[−1,1]. Therefore,

|f⁢(x)−p⁢(x)|≤‖f′′′‖C⁢[−1,1]6⁢|ℓ⁢(x)|for all ⁢x∈[−1,1],

and so

‖f−p‖C⁢[−1,1]≤‖f′′′‖C⁢[−1,1]6⁢‖ℓ‖C⁢[−1,1].

To compute ‖ℓ‖C⁢[−1,1], note that ℓ⁢(x)=x3−x, so ℓ′⁢(x)=3⁢x2−1, which vanishes at x=±1/3. Since ℓ⁢(±1)=0 and ℓ⁢(±1/3)=∓2/(3⁢3), we have ‖ℓ‖C⁢[−1,1]=2/(3⁢3), and so

‖f−p‖C⁢[−1,1]≤‖f′′′‖C⁢[−1,1]9⁢3.

On the larger interval [−2,1], the same argument gives

‖f−p‖C⁢[−2,1]≤‖f′′′‖C⁢[−2,1]6⁢‖ℓ‖C⁢[−2,1].

The only critical points of ℓ are still ±1/3, but now we must also check the endpoint x=−2, where ℓ⁢(−2)=(−1)⁢(−2)⁢(−3)=−6. So ‖ℓ‖C⁢[−2,1]=6, and

‖f−p‖C⁢[−2,1]≤‖f′′′‖C⁢[−2,1].

Since ‖f′′′‖C⁢[−2,1]≥‖f′′′‖C⁢[−1,1], this bound is at least 9⁢3≈15.6 times larger than the bound on [−1,1]. The reason is that [−2,−1] lies outside the nodes, so there we are extrapolating rather than interpolating. For x<−1, all three factors x+1, x, and x−1 of ℓ⁢(x) grow in size as x moves away from the nodes, so |ℓ⁢(x)| grows like |x|3. Inside [−1,1], on the other hand, x is always close to at least one node, which keeps |ℓ⁢(x)| small. ◆

We now move on to proving the error estimates. We will use repeatedly Rolle’s Theorem.

Theorem 2 (Rolle’s Theorem).

Suppose that f∈C⁢[a,b] and f is differentiable on (a,b). If f⁢(a)=f⁢(b), then there is some c∈(a,b) for which f′⁢(c)=0.

Proof of Theorem 1.

We may assume without loss of generality that x0<x1<⋯<xn. Set ξ0,j=xj for all j. We know that f⁢(xj)−p⁢(xj)=0.

By Rolle’s Theorem applied to f⁢(x)−p⁢(x) on each pair of adjacent points ξ0,j, there are points ξ1,j∈(ξ0,j,ξ0,j+1) such that f′⁢(ξ1,j)−p′⁢(ξ1,j)=0. We can then apply Rolle’s Theorem again, but now to f′⁢(x)−p′⁢(x) on each pair of adjacent points ξ1,j, obtaining new points ξ2,j∈(ξ1,j,ξ1,j+1) such that f′′⁢(ξ2,j)−p′′⁢(ξ2,j)=0. Repeating this process, we obtain, for all 1≤k≤n

ξk,j∈(ξk−1,j,ξk−1,j+1),0≤j≤n−k,such that f(k)⁢(ξk,j)−p(k)⁢(ξk,j)=0.

Now, given k and for fixed x∈[a,b]∖{ξk,0,…,ξk,n−k}, define g∈Cn−k+1⁢[a,b] by

g⁢(t)=f(k)⁢(t)−p(k)⁢(t)−(f(k)⁢(x)−p(k)⁢(x))⁢∏j=0n−kt−ξk,jx−ξk,j. (3)

Note that

g⁢(ξk,j)=0andg⁢(x)=0.

So, g⁢(t) has at least n−k+2 roots. Therefore, by repeated application of Rolle’s Theorem, there exists some ξk⁢(x)∈(min⁡(x,ξk,0),max⁡(x,ξk,n−k)) such that g(n−k+1)⁢(ξk⁢(x))=0. Differentiating both sides of (3) n−k+1 times and evaluating at ξk yields

0=g(n−k+1)⁢(ξk⁢(x))=f(n+1)⁢(ξk⁢(x))−(f(k)⁢(x)−p(k)⁢(x))⁢(n−k+1)!⁢∏j=0n−k1x−ξk,j. (4)

To obtain the above, we used that p(n+1)≡0 and that ∏j=0n−k(t−ξk,j) is a polynomial of degree n−k+1 with leading coefficient 1. Rearranging (4) gives

f(k)⁢(x)−p(k)⁢(x)=f(n+1)(n−k+1)!⁢∏j=0n−k(x−ξk,j),

which is exactly the conclusion (2). The case of x=xk,j for some j is immediate since both sides are zero. When k=0, we obtain (1).

The proof of the statement that the points ξk can be chosen such that f(n+1)⁢(ξk) is continuous is omitted here (see the textbook). ∎
