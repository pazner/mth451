1. Let f⁢(x)=sin⁡(x), and let c=0. Recall the nth order Taylor polynomial of f at c is

    Find p1⁢(x), the first order Taylor polynomial of f at c. What is its degree?

  2. (b)

2. Consider the forward difference approximation to the derivative

f′⁢(c)≈f⁢(c+h)−f⁢(c)h-:F.
  1. (a)

    In general, if h is halved, what is expected to happen to the error |f′⁢(c)−F|?

  2. (b)

    What happens in the specific case of f⁢(x)=sin⁡(x) and c=0? (Hint: use Taylor’s Theorem with p2 from question 1).

Solution. The error in the forward difference approximation to the derivative is given by the expression

f′⁢(c)−f⁢(c+h)−f⁢(c)h=−f′′⁢(ξ)2⁢h,

for some ξ between c and c+h. The right-hand side scales like h, so if h is halved, we expect the error to be roughly halved as well. The error will not generally be exactly halved, because we evaluate f′′ at a different ξ.

In the specific case of f⁢(x)=sin⁡(x) and c=0, note that f′′⁢(ξ)=−sin⁡(ξ), and for ξ close to 0, sin⁡(ξ)≈ξ, so this suggests the error may actually be smaller than predicted above. We can make this rigorous using p2⁢(x). Taylor’s Theorem with h gives

sin⁡(h)=p2⁢(h)+sin′′′⁡(ξ)3!⁢h3=h−cos⁡(ξ)6⁢h3.

The forward difference quotient is

f⁢(c+h)−f⁢(c)h =sin⁡(h)−sin⁡(0)h=h−16⁢cos⁡(ξ)⁢h3h
=1−16⁢cos⁡(ξ)⁢h2=sin′⁡(0)−16⁢cos⁡(ξ)⁢h2,

so, because the first and second Taylor polynomials are the same, we get an extra cancellation, and in this particular case, if we halve h, we expect the error to decrease by a factor of about 4.
