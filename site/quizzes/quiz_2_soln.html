1. Let f⁢(x)=x3−2 on the interval [a,b]=[1,2]. You may find the following values of f useful:

x 1 1.25 1.5 1.75 2
f⁢(x) −1 −0.046875 1.375 3.359375 6
  1. (a)

    Perform the bisection method to find x0, x1, and x2, giving the interval [an,bn] at each step.

  2. (b)

    How many iterations n are needed to guarantee that |xn−r|≤2−20=(1,048,576)−1≈10−6, where r is the root of f?

Solution. From the table, f⁢(1)<0 and f⁢(2)>0, so [a0,b0]=[1,2] and x0=1.5. Since f⁢(1.5)>0, f⁢(a0)⁢f⁢(x0)≤0, so [a1,b1]=[1,1.5] and x1=1.25. Since f⁢(1.25)<0, f⁢(a1)⁢f⁢(x1)>0, so [a2,b2]=[1.25,1.5] and x2=1.375.

By the convergence theorem, |xn−r|≤2−(n+1)⁢(b−a)=2−(n+1). This is at most 2−20 when n+1≥20, so n=19 iterations suffice.

2. Now suppose we run the bisection algorithm from Problem 1 on a computer, using double-precision floating point arithmetic. We choose to terminate the algorithm only when bn−an≤xtol.

  1. (a)

    Note r=23 is irrational. Is r∈𝔽? Give an upper bound on the minimum achievable error |xn−r|.

  2. (b)

    What happens to the algorithm when, for example, xtol=2−60?

Solution. (a) Every number in 𝔽 has a finite binary expansion, and so is rational. Since r=23 is irrational, r∉𝔽. Every iterate xn is in 𝔽, so |xn−r|>0 for all n, no matter how many iterations we perform. The floating point numbers in [1,2] are evenly spaced, with spacing ϵ=2−52, and r lies between two consecutive ones. The closer of the two is fl⁡(r), which satisfies

0<|fl⁡(r)−r|≤12⁢ϵ=2−53=u.

So the smallest achievable error is positive, and at most u≈1.1×10−16.

(b) In exact arithmetic, bn−an=2−n, so we would terminate once 2−n≤xtol, i.e. after n=60 iterations when xtol=2−60. In floating point arithmetic, after n=52 iterations, b52−a52=2−52=ϵ, so a52 and b52 are consecutive floating point numbers, with no element of 𝔽 strictly between them. The computed midpoint fl⁡((a52+b52)/2) is therefore equal to either a52 or b52, and in either case the bisection update leaves the interval unchanged. So bn−an=2−52>xtol for all n≥52, and the algorithm never terminates (or runs until maxit). The same happens for any xtol<2−52: the convergence theorem holds in exact arithmetic, but in floating point arithmetic the interval cannot shrink below the spacing of 𝔽 near the root.
