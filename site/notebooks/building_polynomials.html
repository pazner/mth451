Building Polynomials¶

Given distinct nodes $x_0, \ldots, x_n$, the Lagrange polynomials are $$ \ell_j(x) = \prod_{\substack{k=0\\k\neq j}}^n \frac{x - x_k}{x_j - x_k}, $$ and they satisfy $\ell_j(x_i) = \delta_{ij}$.

def lagrange(x, nodes, j):
    """The j-th Lagrange polynomial for the given nodes, evaluated at x."""
    ell = np.ones_like(x)
    for k, xk in enumerate(nodes):
        if k != j:
            ell *= (x - xk) / (nodes[j] - xk)
    return ell

The Lagrange basis¶

We take $n = 5$, with $n + 1 = 6$ equidistant nodes on $[-1, 1]$. Each $\ell_j$ is equal to 1 at $x_j$ and 0 at the other nodes.

Interpolation¶

Let $f(x) = e^x \sin(3x)$, and $y_j = f(x_j)$. The interpolating polynomial is $$ p(x) = \sum_{j=0}^n y_j \ell_j(x). $$

In [4]:
def f(x):
    return np.exp(x) * np.sin(3 * x)


y = f(nodes)


def p_lagrange(x):
    return sum(y[j] * lagrange(x, nodes, j) for j in range(n + 1))

The Vandermonde matrix¶

Writing $p(x) = \sum_{j=0}^n a_j x^j$ in the monomial basis, the conditions $p(x_i) = y_i$ give the linear system $V a = y$, where $V_{ij} = x_i^j$.
